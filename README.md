## Currently working on
**AnytimeReno** (ongoing school group project, team of seven, private repo):
an interior design app with 2D and 3D room editors, drag-and-drop furniture
and first-person walkthroughs.

What I've built so far:
- **3D model import pipeline:** my own STL and OBJ parsers, conversion to GLB
  for WebGL, mesh and texture reduction, and automatic scaling to real-world
  dimensions
- **Furniture interaction:** selecting, dragging and rotating pieces in 3D,
  with collision against walls and other furniture
- **Wall-mounted placement:** items that snap to walls and stay attached as
  the walls are edited
